TicketMuseum — Sistema de Gestión de Taquilla y Visitantes

¡Bienvenido al repositorio oficial de TicketMuseum Este es un sistema de escritorio diseñado profesionalmente para la automatización, control de accesos, venta de boletos y análisis de datos en tiempo real para la administración del museo.
Características Principales:

*   Control de Accesos y Bitácora: Registro de la entrada de visitantes en tiempo real enlazado directamente a la base de datos.
*   Gestión de Taquilla: Interfaz intuitiva para la venta de boletos y control de ingresos.
*   Dashboard Administrativo:Panel de control visual con estadísticas e historial de movimientos.
*   Instalador Automatizado: Distribución profesional mediante un asistente ejecutable que configura el sistema.

Tecnologías Utilizadas:
El sistema fue desarrollado utilizando un stack tecnológico robusto y moderno enfocado en entornos empresariales:

*   Lenguaje de Programación: C# (.NET)
*   Interfaz Gráfica: Windows Presentation Foundation (WPF) 
*   Base de Datos: SQL Server
*   Control de Versiones:Git y GitHub para el flujo de trabajo colaborativo

  Requisitos del Sistema:
  Para ejecutar el entorno de desarrollo o instalar la aplicación, se requiere:
*   Windows 10 o Windows 11
*   .NET SDK (Versión 8.0 o superior recomendada)
*   Microsoft SQL Server

  Instrucciones de Instalación (Para Usuarios)
1. Descarga el archivo TicketMuseumSetUp.exe.
2. Ejecuta el instalador (introduce la contraseña si se solicita).
3. Paso Clave: El asistente te mostrará una pantalla personalizada solicitando el Servidor de Base de Datos SQL. Escribe la instancia instalada en tu equipo (por defecto viene configurado como `.\SQLEXPRESS`).
4. Haz clic en Siguiente y finaliza la instalación.
